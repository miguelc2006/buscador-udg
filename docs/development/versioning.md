# Estrategia de Versionado — [PROYECTO]

## Semantic Versioning (SemVer)
El proyecto sigue el estándar de versionado semántico `MAJOR.MINOR.PATCH`:
- **MAJOR:** Cambios incompatibles con versiones anteriores.
- **MINOR:** Nuevas funcionalidades compatibles.
- **PATCH:** Corrección de errores compatible.

## Conventional Commits
Los mensajes de commit deben seguir la convención:
- `feat:` para nuevas características.
- `fix:` para corrección de errores.
- `docs:` para cambios en documentación.
- `test:` para añadir o modificar pruebas.
- `refactor:` para cambios de código que no corrigen errores ni añaden funciones.
- `chore:` para tareas de mantenimiento.

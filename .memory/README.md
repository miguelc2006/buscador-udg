# Memoria del Agente

## Propósito

Directorio para notas del agente de IA. Estas notas persisten entre conversaciones y ayudan al agente a recordar preferencias, patrones y decisiones.

## Organización

### Archivos sugeridos

- `preferences.md` — Preferencias del usuario (idioma, estilo, etc.)
- `patterns.md` — Patrones detectados en el proyecto
- `learnings.md` — Lecciones aprendidas de errores
- `shortcuts.md` — Comandos y atajos frecuentes

## Formato

Cada archivo debe ser conciso y estructurado:

```markdown
# [Título]

## [Categoría]
- [Hecho 1]
- [Hecho 2]

## [Categoría]
- [Hecho 1]
```

## Reglas

- Solo información verificada
- Actualizar cuando cambie
- Eliminar información obsoleta
- Mantener conciso (máx 200 líneas por archivo)
